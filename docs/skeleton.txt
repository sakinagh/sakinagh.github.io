                # Because GitHub Pages does not automatically convert raw .md files into
                # styled HTML pages without an underlying framework like Jekyll, will
                # use the "Pure Link Approach" to display them.
                #
                # How it works in your HTML code:
                # In your `research.html` or custom conference landing page, do NOT link 
                # to the relative path ("research-materials/swpa-2026/references.md"). 
                # If you do, the browser will just download the file or display it as unformatted text.
                #
                # Instead, link directly to the file's main user-facing URL on your 
                # main GitHub repository code view.
                #
                # Syntax Example for your HTML anchor tag:
                # <a href="https://github.com/sakinagh/sakinagh.github.io/blob/main/research-materials/swpa-2026/references.md" target="_blank">
                #    View Reference List & Data Logs
                # </a>
                #
                # Result: When a user scans your poster's QR code or clicks the link, 
                # GitHub will intercept the request and beautifully render your Markdown 
                # file automatically using their clean, readable repository interface.
